# Курс по UX/UI дизайну · Модуль 7

Трекер исследования перед проектом — материал модуля 7 «Анализ потребностей пользователя и ниши».

**Страница:** https://altronuslive-glitch.github.io/uxui-module-7/

## Что это

Напоминание о маршруте исследования, а не форма для дотошного заполнения. Пять разделов, шесть блоков, 30 пунктов: от брифинга и анализа бизнеса до проверки принятых решений. У каждого блока написано, зачем он нужен и что после него остаётся на руках.

Отметки и заметки сохраняются в браузере ученика (localStorage), на сервер ничего не отправляется. Прогресс у каждого свой.

## Как устроено

Одна самодостаточная HTML-страница: разметка, стили и скрипт в одном файле. Единственная внешняя зависимость — шрифт Onest с Google Fonts; без интернета подхватится системный шрифт, вёрстка не поедет.

Содержимое трекера лежит в массиве `PHASES` внутри `index.html` — разделы, блоки и пункты правятся там.

## Обновление

Исходник материала хранится в рабочем проекте курса:
`Материалы/Модуль 7/Трекер исследования.html`

После правок файл копируется сюда как `index.html`, меняется заголовок вкладки на «Курс по UX/UI дизайну · Модуль 7» и добавляются метатеги `robots`, `description`, `theme-color` и иконка. Затем `git commit` и `git push` — GitHub Pages обновляет страницу за минуту-две.

Страница закрыта от поисковой индексации: `robots.txt` и метатег `noindex`. Ссылка работает у всех, у кого она есть.
